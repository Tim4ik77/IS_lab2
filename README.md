# Информационная система билетов

Лабораторная работа №2 по ИС.

Приложение ведёт учёт билетов, событий и площадок. Билеты можно искать по идентификатору, фильтровать и сортировать. Серверная часть использует Spring MVC, JPA и EclipseLink, база данных — PostgreSQL, интерфейс написан на React.

## Импорт билетов

Приложение принимает JSON-файл размером до 5 МиБ с массивом от 1 до 1000 билетов. Если событие или площадка с таким названием уже есть в справочнике, приложение сверяет остальные поля. При совпадении билет связывается с существующей записью. Если поля различаются, импорт всего файла отменяется. 
[Пример файла](frontend/public/import-example.json)

Все билеты из файла сохраняются в одной транзакции. В истории импорта пользователь видит свои загрузки, а администратор - загрузки всех пользователей. Для успешной загрузки указано число добавленных билетов, для неудачной - причина ошибки.
